# 9Wickets — Official Agent List & Support (Static Landing Page)

Pure **HTML + CSS + JavaScript** (jQuery + Vue 3 + Tailwind CDN) — single `index.html` file.
No PHP, no database, no Node.js, no build step.

## What's inside

- **Hero carousel** — official agent list / 24-7 support / complaint center (auto-rotate + Ken Burns)
- **Stats strip** — verified agents, districts, support hours (count-up animation)
- **কেন এই লিস্টটাই আসল?** — trust bento grid
- **Official Agent Network** — real banner from the agent portal, Master Admin (Asif Khalid),
  Sub-Admins SA1/SA2, CS1/CS2 live cards, **22 verified master agents** in an auto-scrolling
  carousel with copy-number buttons, "কাকে কখন মেসেজ করবেন" guide table, safe-account block,
  ৪-ধাপ safety steps
- **Customer Service** — female support agent photo, CS1/CS2 WhatsApp cards
- **Complaint Center** — quick complaint form that opens WhatsApp pre-filled
- **FAQ** — Bangla accordion
- Light/Dark theme toggle, floating WhatsApp button, full mobile-first responsive

All content (names, numbers, links, texts) is editable in one place — the `c: { ... }`
object near the bottom of `index.html`.

## Official source

- 9wicketsagentlist.com — the official agent portal this page mirrors
